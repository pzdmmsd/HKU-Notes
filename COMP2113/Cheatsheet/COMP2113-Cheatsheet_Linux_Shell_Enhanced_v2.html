Shell Script Syntax

#!/bin/bash
VAR_NAME=value            # no spaces around =
read VAR_NAME             # read stdin
echo "$VAR_NAME"          # double quotes expand variables
echo 'literal $VAR_NAME'  # single quotes do not expand
cmd_out="$(cmd)"          # command substitution
path="Module 1/a.cpp"     # double quote paths with spaces
echo "$USER $HOME"        # expands variables, keeps spaces as one arg
echo '$USER $HOME'        # prints literal $USER $HOME
echo \$HOME               # backslash escapes one special char
echo "*.cpp"              # no wildcard expansion inside quotes
echo *.cpp                # wildcard expands to matching filenames
cmd `date`                # old command substitution; prefer $(date)
${#a}                     # string length
${a:pos:len}              # substring, index starts at 0
${a/find/replace}         # replace first occurrence
${a//find/replace}        # replace all occurrences
let "x = x + 1"           # arithmetic
x=$((x + 1))              # arithmetic expansion
echo "error" >&2          # output to stderr
exit 1                    # non-zero status means failure

Arguments, Tests, Control

1. Script arguments
   $0 script name; $1 first arg; ${10} tenth arg
   $# arg count; $? last exit status; "$@" all args safely
   Example: ./run.sh in.txt out.txt
     $0=./run.sh, $1=in.txt, $2=out.txt, $#=2
   for a in "$@"; do echo "$a"; done  # preserves spaces in args

2. String tests
   [ "$s" ]                 # non-empty string
   [ "$a" == "$b" ]         # string equal
   [ "$a" != "$b" ]         # string not equal
   [ "$a" \> "$b" ]         # lexicographic after; escape >
   Example: if [ "$name" == "Tom" ]; then echo match; fi

3. File and integer tests
   [ -e f ] exists; [ -f f ] regular file; [ -d p ] directory
   [ -s f ] non-empty; [ -r f ] readable; [ -w f ] writable; [ -x f ] executable
   [ "$a" -eq "$b" ]; -ne not equal; -lt/-le less; -gt/-ge greater
   Example: if [ -f "$1" ] && [ -r "$1" ]; then cat "$1"; fi

4. if / elif / else
   if [ cond ]; then cmd; elif [ cond2 ]; then cmd2; else cmd3; fi
   Example: if [ "$#" -lt 2 ]; then echo "usage" >&2; exit 1; fi

5. Loops
   for i in $list; do cmd; done        # word-splitting happens
   for i in "$@"; do echo "$i"; done   # safer for arguments
   for f in *.cpp; do g++ -std=c++11 "$f" -o "${f%.cpp}"; done
   for ((i=0; i<n; i++)); do echo "$i"; done
   for ((i=10; i>=0; i-=2)); do sum=$((sum+i)); done

Compile and Makefile

1. Manual compile commands
   g++ -std=c++11 -pedantic-errors -Wall main.cpp -o main
     # compile one program; -o names executable
   g++ -c gradebook.cpp -o gradebook.o
     # compile only to object file, no linking yet
   g++ main.o gradebook.o -o main
     # link object files into executable
   ./main < in.txt > out.txt
     # run with redirected input/output

2. Typical Makefile
   CXX = g++
   CXXFLAGS = -std=c++11 -pedantic-errors -Wall
   OBJS = main.o gradebook.o

   main: $(OBJS)
        $(CXX) $(CXXFLAGS) $(OBJS) -o $@

   %.o: %.cpp
        $(CXX) $(CXXFLAGS) -c $< -o $@

   main.o: main.cpp gradebook.h
   gradebook.o: gradebook.cpp gradebook.h

   .PHONY: clean tar
   clean:
        rm -f *.o main
   tar:
        tar -czvf submit.tgz *.cpp *.h Makefile

3. Makefile syntax
   target: dependencies        # if dependency newer, rebuild target
        recipe command         # recipe line must start with TAB
   $@ target name; $< first dependency; $^ all dependencies
   make        # builds first target
   make clean  # runs clean target
   make tar    # creates submission archive

4. .h files
   Header .h: declarations, struct/class definitions, function prototypes.
   Source .cpp: function definitions/implementation.
   Use #include "gradebook.h" in .cpp that needs declarations.
   Do not compile .h alone; compile .cpp that includes it.
   If gradebook.h changes, every .o depending on it must rebuild.
   Header guard prevents double include:
     #ifndef GRADEBOOK_H
     #define GRADEBOOK_H
     ...
     #endif

Reference vs Pointer Swap

void swapByRef(int& a, int& b) {
  int t = a; a = b; b = t;
}

void swapByPtr(int *a, int *b) {
  int t = *a; *a = *b; *b = t;
}

Call pointer version: swapByPtr(&x, &y);
Reference is an alias and cannot be reseated.
Pointer stores an address, may be nullptr, can point elsewhere.

Pointer Patterns

Array as pointer:
int a[10]; int *p = a; p[i] == *(p+i);
Passing array: void fill(int a[], int n);  # array modified in caller

Struct pointer:
struct Student { char name[100]; int uid; };
Student s; Student *sp = &s;
(*sp).uid = 1; sp->uid = 1;   # arrow is shorthand
strcpy(sp->name, "Tim");      # cannot assign char array by =

C dynamic memory:
int *p = malloc(n * sizeof *p);
if (!p) exit(1);
free(p); p = nullptr;
malloc/calloc/realloc return void*; C auto-converts, C++ needs cast/new.

Pointer Pitfalls

Dangling pointer: pointer still stores freed/deleted address.
Memory leak: allocated memory is no longer reachable.
Double free/delete: releasing same allocation twice is undefined.
Wrong deallocation pair: new[] must use delete[], malloc must use free.
Off-by-one: last valid index is n-1; a+n points one past last only.
Never dereference one-past-last, nullptr, or an uninitialized pointer.

Dynamic array resize pattern:
T *b = new T[newSize];
copy old items; delete[] a; a = b; b = nullptr;

Linked List Pointer Rules

Use cur for traversal; do not move head unless deleting/changing head.
while (cur != nullptr) { process(cur); cur = cur->next; }
For deletion keep prev:
if (prev == nullptr) head = cur->next; else prev->next = cur->next;
delete old node after saving next pointer.

head insert: n->next = head; head = n;
tail insert: if empty head=tail=n; else tail->next=n; tail=n;
Sequential access: kth node needs walking from head, O(k).
Array random access O(1); linked-list insert/delete after node O(1).

Linear Search / Selection Sort

int linSearch(T a[], int n, T x) {
  for (int i = 0; i < n; ++i)
    if (a[i] == x) return i;
  return -1;
}

void selSortAsc(T a[], int n) {
  for (int i = 0; i < n - 1; ++i) {
    int m = i;
    for (int j = i + 1; j < n; ++j)
      if (a[j] < a[m]) m = j;
    if (m != i) { T t = a[i]; a[i] = a[m]; a[m] = t; }
  }
}

Linked List Insert / Delete

void insertAtEnd(Node*& head, Node* n) {
  Node* cur = head;
  if (cur == nullptr) { head = n; return; }
  while (cur->next != nullptr) cur = cur->next;
  cur->next = n; n->next = nullptr;
}

void deleteWithVal(Node*& head, int val) {
  Node *cur = head, *prev = nullptr;
  while (cur != nullptr) {
    if (cur->data == val) {
      if (prev == nullptr) head = cur->next;
      else prev->next = cur->next;
      delete cur;
      cur = prev ? prev->next : head;
      continue;   # delete all occurrences
    }
    prev = cur; cur = cur->next;
  }
}

Linked List Clear / Reverse

void deleteList(Node*& head) {
  Node *cur = head, *next;
  while (cur != nullptr) {
    next = cur->next;
    delete cur;
    cur = next;
  }
  head = nullptr;
}

void reverseList(Node*& head) {
  Node *cur = head, *prev = nullptr, *next;
  while (cur != nullptr) {
    next = cur->next;
    cur->next = prev;
    prev = cur;
    cur = next;
  }
  head = prev;
}

struct in C++

struct Point {
  int x, y, z;
  Point(int x, int y, int z) : x(x), y(y), z(z) {}
  double distance(const Point& p) {
    return sqrt(pow(x-p.x,2)+pow(y-p.y,2)+pow(z-p.z,2));
  }
  bool operator<(const Point& p) {
    return x < p.x || (x == p.x && y < p.y) ||

STL Iterators

STL = containers + iterators + algorithms.
Iterator belongs to one container type; do not mix vector/list/map iterators.

vector<int>::iterator it = v.begin();
cout << *it; *it = 100; ++it;          # dereference changes item
c.begin() points first item; c.end() points one past last, not a real item.
Never dereference end(); use it != c.end() as loop condition.

Forward:       =, ++, *, ==, !=
Bidirectional: forward + --            # list/map/set
Random access: bidirectional + +, -, +=, <, it[i]  # vector/array
For vector, v.end()-v.begin() == v.size(); for list/map/set this is invalid.
Iterator is not necessarily a memory address; it hides container structure.

Recursion Patterns

Recursive function = base case + recursive call on smaller input.
Must eventually reach base case; otherwise stack overflow.

int fact(int n) { if (n == 0) return 1; return n * fact(n-1); }
int fib(int n) { if (n < 2) return n; return fib(n-1)+fib(n-2); }
int gcd(int x, int y) { if (y == 0) return x; return gcd(y,x%y); }
bool pal(string s) {
  return s.length() < 2 ||
    (s[0] == s[s.length()-1] && pal(s.substr(1,s.length()-2)));
}

vector / list / set / map

#include <vector>
vector<int> v;
v.push_back(x); v.pop_back(); v[i]; v.at(i); v.size(); v.empty();
v.front(); v.back(); v.capacity(); v.resize(n); v.reserve(n);
v.insert(pos,val); v.erase(pos); v.clear(); v.swap(v2);
push_back/pop_back/index/size are O(1); push_back copies the item.
Pros: random access O(1), compact memory, works with std::sort.
Cons: middle insert/erase costly; reallocation may invalidate iterators.
Use vector when random access and sorting are needed.
for (vector<T>::iterator it = v.begin(); it != v.end(); ++it)
  cout << *it;
for (auto it = v.begin(); it != v.end(); )
  if (condition) it = v.erase(it); else ++it;

#include <list>
list<int> l;
l.push_back(1); l.push_front(2);
l.pop_back(); l.pop_front(); l.size(); l.front(); l.back();
l.sort(); l.reverse();                 # list member sort/reverse
list<T>::iterator it;  # bidirectional, no l[i], no random access
Pros: O(1) insert/erase at known position; stable iterators.
Cons: no index/random access; extra pointer memory; cannot std::sort.
Use list for frequent insertion/deletion, not kth-item access.

#include <set>
set<int> s;
s.insert(3); s.insert(3);              # duplicate ignored
s.count(3); s.find(3); s.erase(3); s.size(); s.empty();
for (auto it = s.begin(); it != s.end(); ++it) cout << *it;
Set stores unique keys in sorted order; key type needs operator<.
Default order is ascending; rbegin/rend visits reverse order.
Pros: unique + sorted + O(log n) find/insert/erase.
Cons: no duplicates, no index access, cannot modify key through iterator.

#include <map>

  cout << it->first << it->second;     # ascending key order

map keeps keys sorted; begin() gives smallest key.
Pros: key-value lookup/update O(log n), sorted by key.
Cons: no duplicate keys; m[key] inserts default if absent.
v1 = v2; l1 = l2; m1 = m2;             # assignment copies elements

STL Algorithms / Sort Details

#include <algorithm>
sort(v.begin(), v.end());              # default ascending by operator<

sort(v.rbegin(), v.rend());            # descending via reverse iterators
sort(v.begin(), v.end(), greater<int>()); # descending comparator
reverse(v.begin(), v.end());           # reverse current order, no sorting
std::find(v.begin(), v.end(), x);      # linear search, returns iterator/end

Do not call std::sort on list/map/set iterators; they are not random access.
Use l.sort() for list sorting; l.reverse() reverses list order.
map/set are already sorted by key; iteration visits ascending keys.
Use rbegin()/rend() to visit vector/list/set/map in reverse order.
For user-defined keys/items used in set/map/sort, define operator<:
bool operator<(const Email& a, const Email& b) {
  if (a.sender != b.sender) return a.sender < b.sender;
  return a.subject < b.subject;
}

Complexity: vector random access O(1); list kth access O(k);
map/set insert/find/erase O(log n); sort average O(n log n).

int binSearch(int a[], int l, int r, int x) {
  if (r >= l) {
    int m = l + (r-l)/2;
    if (a[m] == x) return m;
    if (a[m] > x) return binSearch(a,l,m-1,x);
    return binSearch(a,m+1,r,x);
  }
  return -1;
}

C vs C++ Differences

1. Language/library
   C has no cin/cout, string, vector, reference &, new/delete, class methods.
   Use printf/scanf/fgets, char arrays, malloc/free, struct + functions.
2. Functions and arrays
   C function must be declared before use; no default pass-by-reference.
   Array parameter becomes pointer: void f(int a[]) == void f(int *a).
   sizeof(array) works only in same scope; in function it is pointer size.
3. Memory and strings
   void* from malloc auto-converts in C; C++ requires cast or use new.
   char array cannot use = after declaration; use strcpy/strncpy.
4. Input traps
   scanf("%s", s) no & for char array; scanf("%d", &x) needs address.
   Mixing scanf then fgets leaves newline; consume newline first.
5. Safety
   Check every allocation and file open before dereference/use.

Char Array / C-String

char name[] = "John";       # auto size incl. '\0'
char name[16] = "John";     # fixed buffer
name[i] accesses one char; name[2] = 'a';
cin >> name; scanf("%15s", name); # no spaces, no & for char array
cout << name; printf("%s", name);

C-string ends with '\0'; ensure enough space for terminator.
strlen(s): count chars before '\0', not including terminator.
strcpy(dest, src): copy src incl. '\0'; dest must be large enough.
strncpy(dest,src,n): may omit '\0' if full; check terminator manually.
strcat(dest, src): append src; dest must have remaining capacity.
strcmp(a,b): <0 if a<b, 0 equal, >0 if a>b; do not use ==.
strchr(s,c): first char c; strrchr(s,c): last char c.
strstr(s,sub): first substring; returns pointer/nullptr.
strtok(s,delim): tokenizes by writing '\0' into s; destroys original.

Must use / need C-string when:
1. C library API: printf/scanf/fgets/strlen/strcpy/strcmp.
2. char buffer required: char a[100], fixed memory, manual '\0'.
3. argv and legacy APIs; older file open may need path.c_str().
Conversions:

Exam Pitfalls

1. Input
   cin >> s stops at whitespace; getline(cin,s) reads line.
   scanf("%s",s) may overflow unless width is given: "%99s".
   After scanf, fgets may read leftover '\n'; consume or handle newline.
2. Pointers / memory
   int *a, b; means only a is pointer; write int *a, *b for two pointers.
   Never dereference nullptr/uninitialized/one-past-end pointer.
   new[] pairs with delete[]; malloc/calloc/realloc pairs with free.
   Do not assign realloc result directly to p before checking nullptr.
3. Arrays / strings
   sizeof(array) inside function is pointer size, not element count.
   char array cannot be compared/assigned by == or =; use strcmp/strcpy.
   Last valid array index is size-1; loop condition usually i < size.
4. STL / algorithms
   m[key] creates default value; use count() to test existence.
   sort uses half-open range [first,last); last iterator not included.
5. Testing / output
   Test empty, one item, duplicates, max size, no match, all same.
   Use diff to catch invisible spaces, missing newline, and line breaks.
   Use long long for large counts/totals; watch int division truncation.
